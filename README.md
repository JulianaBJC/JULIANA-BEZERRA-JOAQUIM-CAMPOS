## 🎨 O Projeto & Conceito Visual

O portfólio foi projetado com uma identidade visual premium inspirada na **estética acadêmica e corporativa de alto escalão**:
- **Paleta de Cores**: Tons intensos de azul escuro acadêmico (`#0b1a30`), contrastados com dourados nobres e sutis fundos off-white para um visual confortável e luxuoso.
- **Tipografia**: Títulos elegantes em fontes serifadas clássicas, combinando perfeitamente com elementos técnicos legíveis em fontes modernas e mono-espaçadas.
- **Narrativa Fluida**: Rolagem fluida pontuada por micro-animações requintadas com transições suaves que guiam o leitor através de blocos sobre a história, o manifesto "Cuidar Sem Adoecer", projetos digitais, e resultados.

## ⚡ Tecnologias Utilizadas

Este projeto foi construído utilizando as melhores e mais modernas práticas de desenvolvimento front-end:

*   **[React 19](https://react.dev/)** — Framework de interface declarativa e moderna.
*   **[TypeScript](https://www.typescriptlang.org/)** — Tipagem estática para robustez, escalabilidade e manutenibilidade do código.
*   **[Vite](https://vite.dev/)** — Build tool ultra-rápida de próxima geração.
*   **[Tailwind CSS v4](https://tailwindcss.com/)** — Framework utilitário de CSS totalmente otimizado para estilo moderno e responsivo.
*   **[Motion (Framer Motion)](https://motion.dev/)** — Engine de animação de alto desempenho para transições, animações de entrada física, e interações realistas de navegação.
*   **[Lucide React](https://lucide.dev/)** — Conjunto de ícones vetoriais modernos e consistentes.
*   **[FormSubmit](https://formsubmit.co/)** — Canal de integração segura para envio direto de propostas acadêmicas e comerciais com anti-spam honeypot.

## 🛠️ Como Executar Localmente

Se você deseja executar ou contribuir para este projeto em seu ambiente local, siga o passo a passo abaixo:

1. **Clonar o Repositório**:
   ```bash
   git clone https://github.com/JulianaBJC/JULIANA-BEZERRA-JOAQUIM-CAMPOS.git
   cd JULIANA-BEZERRA-JOAQUIM-CAMPOS
   ```

2. **Instalar Dependências**:
   ```bash
   npm install
   ```

3. **Iniciar o Servidor de Desenvolvimento**:
   ```bash
   npm run dev
   ```
   Acesse no navegador: `http://localhost:3000`

4. **Gerar Versão de Produção**:
   ```bash
   npm run build
   ```
